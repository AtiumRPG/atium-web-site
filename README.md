# Atium RPG Manager website

Recreation of the [Atium landing page](https://gabrielxgm.github.io/atium-page/) as a standalone Vite and React project. The page design, copy, and screenshots come from the [original repository](https://github.com/gabrielxgm/atium-page/).

The original Figma Make files remain in `.figma/`, and `vite.config.ts` keeps their integration alongside normal Vite development and builds.

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and create a production build in `dist/`.
